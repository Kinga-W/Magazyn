# Magazyn

Aplikacja do zarządzania magazynem z przedmiotami różnej kategorii.

##  Instalacja

**Zainstaluj zależności**:
   ```bash
   pip install -r projekt/requirements.txt
   ```

##  Uruchomienie

```bash
python main.py
```

## Struktura projektu

```
projekt/
├── data/               # Dane potrzebne aplikacji
├── src/                # Kod
├── main.py             # Plik do uruchomienia
├── requirements.txt    # Zależności
└── README.md           # Tu jesteś
```
